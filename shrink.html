Model Shrinker

GitHub's website only takes files up to 25 MB. Most of a Meshy model's size is its texture pictures, so this page re-saves them smaller (JPEG, at most the size you pick). The shape, the skeleton and the animations stay exactly the same. Nothing gets uploaded anywhere: it all happens in this browser tab.

  1. Drop the .glb file from Meshy in the box below (or click it to pick the file).
  2. Type the friend's name. That becomes the file name (e.g. sam → sam.glb).
  3. Click Shrink. The small file downloads to your Downloads folder.
  4. Upload that file to public/models/ on GitHub, like before.
